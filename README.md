# 🎓 Student Performance Tracker

A Python and SQLite-based student performance management system that allows users to store, search, analyze, and manage student marks.

## 🚀 Features

- Add students
- View all students
- Search students by name
- Calculate student average
- Find the top-performing student
- Delete students
- Input validation
- Persistent SQLite database
- Handles invalid marks and input errors

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- Python `sqlite3` module
